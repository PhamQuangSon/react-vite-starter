# React Vite Starter

A minimal browser-focused starter for building React applications with Vite, TypeScript, Tailwind CSS, and TanStack Router.

## Stack

- React 18 + TypeScript
- Vite 5
- TanStack Router
- Tailwind CSS with class-based dark mode
- Zustand for persisted client theme state
- Radix UI primitives and Lucide icons
- Jest + Testing Library for unit tests
- Playwright for end-to-end tests
- ESLint + Prettier + Husky + Commitlint
- pnpm 9

## Development

```bash
pnpm install
pnpm dev
```

The starter entrypoint is `src/main.tsx`; the application shell is in `src/App.tsx`.

## Commands

| Command | Purpose |
| --- | --- |
| `pnpm dev` | Start the Vite development server |
| `pnpm build` | Create the production bundle |
| `pnpm preview` | Preview the production bundle |
| `pnpm test -- --runInBand` | Run Jest unit tests |
| `pnpm test:e2e` | Run Playwright tests |
| `pnpm lint` | Run ESLint |
| `pnpm format .` | Format supported files |

## Structure

```text
src/
  components/       Shared components and UI primitives
  hooks/            Reusable React hooks
  layout/           Application shell components
  lib/              Small shared helpers
  routes/           TanStack Router route files
  store/            Zustand stores
  assets/           Static imported assets
  App.tsx           Router and global effects
  main.tsx          Browser entrypoint
```

`src/routeTree.gen.ts` is generated by TanStack Router. Add or change route files instead of editing the generated file directly.

## Conventions

- Use `@/*` for imports from `src/*`.
- Use `@/assets/*` for static assets.
- Keep components small and typed.
- Reuse existing components and Tailwind patterns before adding abstractions.
- Keep the base browser-only; do not add backend, database, Rust, or WebAssembly code to the starter.
